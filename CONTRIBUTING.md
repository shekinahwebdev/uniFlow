# 🤝 Contributing Guide

Thank you for showing interest in contributing to the Timetable Generator project 🙌

This project is still in active development, and contributions are welcome.

---

## Branch Workflow

To keep the `main` branch stable:

- Do not push directly to `main`
- Use the `development` branch for active work
- Create your own feature branch from `development`

Example:

```bash
git checkout development
git checkout -b feature/your-feature-name
```
